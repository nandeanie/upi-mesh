Offline payment network

UPI, even when the internet isn't.

Encrypted payment packets hop phone-to-phone over Bluetooth until one gets connectivity. Then the backend settles the payment exactly once — no matter how many bridges upload it at the same time.

Tamper with a packet

A malicious relay flips one character of the ciphertext. The AES-GCM auth tag must reject it.

Replay an uploaded packet

The bridge uploads the same packet again. The idempotency gate must drop it.

Race: many bridges, one payment

The same packet hits the backend through several bridges at the same instant. Exactly one may settle.
